# Creative Resources: Story Writing & 3D Assets

This document provides curated lists of repositories and resources for creative projects, including story writing tools and 3D asset collections.

---

## Story Writing Repositories (10)

### 1. **Manuskript**
Open-source tool for writers using the snowflake method to develop stories from a single idea into complex narratives with detailed characters, plots, and universes.

- **Features**: Outliner, character management, plot development, full-screen distraction-free mode
- **Platform**: Cross-platform (Linux, Windows, macOS)
- **GitHub**: https://github.com/olivierkes/manuskript
- **Website**: https://www.theologeek.ch/manuskript/

### 2. **novelWriter**
Open source plain text editor designed specifically for writing novels, using minimal Markdown-inspired formatting with metadata syntax for comments and cross-referencing.

- **Features**: Minimal formatting, project organizer, export to multiple formats
- **Platform**: Linux, Windows, macOS
- **GitHub**: https://github.com/vkbo/novelWriter

### 3. **bibisco**
Novel writing software with comprehensive character development, scene organization, and revision management.

- **Features**: Character deep-dive tools, chapter/scene management, export to PDF/DOCX/TXT, full-featured text editor
- **Platform**: Cross-platform
- **GitHub**: https://github.com/andreafeccomandi/bibisco

### 4. **Twine**
Open-source tool for creating interactive, nonlinear stories without coding (but extensible with JavaScript/CSS for advanced users).

- **Features**: Visual story mapping, no code required, publishes to HTML, supports variables and conditional logic
- **Platform**: Web-based, works everywhere
- **Website**: https://twinery.org/
- **Latest Version**: 2.11.0 (Nov 2025)

### 5. **Ink**
Powerful scripting language for interactive narrative, used in games like "80 Days" and "Heaven's Vault" by inkle Studios.

- **Features**: Flow control, branching narratives, integration with game engines (Unity)
- **Editor**: Inky (free desktop editor)
- **GitHub**: Part of inkle's toolkit
- **Resources**: https://marcosecchi.github.io/resources/pages/gamedev_storytelling_ink.html

### 6. **novelibre**
Novel organizer that integrates with LibreOffice/OpenOffice for the actual writing, providing structured manuscript management.

- **Features**: Chapter/scene organization, integration with Writer, export formatted manuscripts
- **Platform**: Cross-platform (requires LibreOffice/OpenOffice)
- **GitHub**: https://github.com/peter88213/novelibre

### 7. **mdnovel**
Novel writing application using Markdown/YAML format for easy readability and version control.

- **Features**: Single-file storage, Markdown-based, pandoc export to multiple formats
- **Platform**: Cross-platform
- **GitHub**: https://github.com/peter88213/mdnovel

### 8. **Awesome Interactive Fiction**
Curated list of interactive fiction frameworks, tools, and resources on GitHub.

- **Content**: Tools, engines, tutorials, example projects
- **Covers**: Twine, Ink, Inform7, ChoiceScript, and more
- **GitHub**: https://github.com/tajmone/awesome-interactive-fiction

### 9. **Story Generator Tools (GitHub Topic)**
Collection of AI-powered and algorithmic story generators for creative inspiration.

- **Features**: GPT-based generators, plot generators, character generators
- **Use Case**: Overcome writer's block, generate ideas
- **Browse**: https://github.com/topics/story-generator

### 10. **Writing Resources by taw00**
Comprehensive collection of free and open-source applications for writers.

- **Content**: Editors, organizers, formatters, reference materials
- **Platform**: Multi-platform options
- **GitHub**: https://github.com/taw00/writing-resources

## 3D Asset Resources & Repositories (10)

### 1. **NASA 3D Resources**
Official NASA repository with spacecraft, planets, satellites, and space-related 3D models, textures, and images.

- **Content**: Space exploration assets, scientifically accurate models
- **License**: NASA Open Source (generally public domain)
- **GitHub**: https://github.com/nasa/NASA-3D-Resources
- **Website**: https://nasa3d.arc.nasa.gov/

### 2. **awesome-cc0**
Curated list of CC0 (public domain) licensed assets from across the internet, including 900+ 3D models.

- **Content**: 300+ VRM/FBX avatars, textures, HDRIs, game assets
- **License**: CC0 (100% free for any use, including commercial)
- **GitHub**: https://github.com/madjin/awesome-cc0

### 3. **awesome-blender**
🪐 Comprehensive list of Blender addons, tools, tutorials, and 3D resources.

- **Content**: Addons, plugins, scripts, tutorials, free models
- **Formats**: .blend, glTF, FBX, OBJ
- **GitHub**: https://github.com/agmmnn/awesome-blender

### 4. **Game Dev Free Resources**
Repository offering free assets for game developers, including 2D/3D art, sound effects, and music.

- **Content**: Characters, environments, props, audio assets
- **Use Case**: Indie game development
- **GitHub**: https://github.com/teamgravitydev/gamedev-free-resources

### 5. **glTF Sample Models (Khronos Group)**
Official glTF format sample models from the Khronos Group.

- **Content**: Reference models for testing glTF implementations
- **Formats**: glTF, GLB
- **GitHub**: https://github.com/KhronosGroup/glTF-Sample-Models

### 6. **Sketchfab**
Massive online platform for discovering, publishing, and sharing 3D models with 3D viewer.

- **Content**: Millions of models across all categories
- **Features**: 3D preview before download, Creative Commons & paid options
- **Formats**: .fbx, .obj, .gltf, .blend, and more
- **Website**: https://sketchfab.com/
- **Tip**: Use "Downloadable" filter to find free models

### 7. **Poly Haven** (formerly Poly.pizza)
100% free, CC0-licensed 3D assets, HDRIs, and textures.

- **Content**: High-quality PBR materials, HDRIs, 3D models
- **License**: CC0 Public Domain
- **Formats**: Multiple formats available
- **Website**: https://polyhaven.com/

### 8. **ambientCG**
2000+ PBR materials, HDRIs, and more, all CC0 public domain.

- **Content**: Textures, seamless materials, HDR lighting
- **License**: CC0 (no attribution required)
- **Use Case**: Realistic rendering, game development
- **Website**: https://ambientcg.com/

### 9. **OpenGameArt**
Community-driven repository for free and open-source game assets.

- **Content**: 2D sprites, 3D models, textures, sounds, music
- **Licenses**: Various (CC0, CC-BY, GPL, etc.)
- **Community**: Active forums and collaborations
- **Website**: https://opengameart.org/

### 10. **itch.io - CC0 3D Assets**
Curated collection of public domain 3D models and textures on itch.io.

- **Content**: Kenney asset packs, KayKit collections, low-poly assets
- **License**: CC0 for featured collections
- **Popular Packs**: Kenney Game Assets All-in-1 (40k+ assets), KayKit collections
- **Website**: https://itch.io/game-assets/assets-cc0/tag-3d

## Tips for Using These Resources

### For Story Writing:
1. **Version Control**: Use Git/GitHub to track your manuscript versions
2. **Plain Text**: Tools like novelWriter and mdnovel use plain text, making them Git-friendly
3. **Collaboration**: Markdown-based tools integrate well with collaborative workflows
4. **Interactive Fiction**: Start with Twine (easiest), move to Ink for game integration

### For 3D Assets:
1. **License Check**: Always verify license before use (CC0 = most permissive)
2. **Format Compatibility**: Check if your engine/tool supports the asset format
3. **Optimization**: Game assets may need LODs (Levels of Detail) for performance
4. **Attribution**: Some licenses require credit - keep track of your sources
5. **Testing**: Preview models before downloading when possible (Sketchfab allows this)
